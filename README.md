# Veil Browser

A simple QT 6 Chromium based web browser written in C++

## Usage

- Install all the usual build tools like `gcc`, `make` etc.
- Install [Qt 6.12 LTS](https://doc.qt.io/qt-6/get-and-install-qt.html) with all its web engine components.
- Then run the following commands:

```bash
mkdir build
cd build
qmake ..
make -j
```

You should now be able to run the `veilbrowser` executable inside the `build/` directory.
